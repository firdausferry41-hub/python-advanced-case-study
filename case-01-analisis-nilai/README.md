# Case 01 — Analisis Nilai Mahasiswa

## Masalah
Bagian akademik perlu menghitung nilai akhir, menemukan mahasiswa dengan nilai di atas 80, membuat ranking, dan menentukan mahasiswa terbaik.

## Konsep Python
- **List comprehension** membuat data baru yang berisi nilai akhir.
- **Lambda** menjadi kunci pengurutan berdasarkan nilai akhir.
- **Filtering** memilih mahasiswa yang nilainya di atas 80.
- **Sorting** mengurutkan nilai dari tertinggi ke terendah.

Rumus: nilai akhir = (tugas × 30%) + (UTS × 30%) + (UAS × 40%).

## Cara menjalankan
```bash
python main.py
```
